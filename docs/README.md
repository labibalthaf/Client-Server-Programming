# Folder docs/

Letakkan screenshot aplikasi di sini agar tampil di README utama:

| Nama file         | Isi                                              |
|-------------------|--------------------------------------------------|
| `admin.png`       | Tampilan halaman Admin (form + hasil live)       |
| `voter.png`       | Tampilan halaman Voter (tombol opsi / bar hasil) |

Cara mengambil screenshot:
1. Jalankan server (`npm start`) dan buka halaman di browser.
2. Ambil screenshot (Windows: `Win + Shift + S`).
3. Simpan dengan nama `admin.png` dan `voter.png` di folder `docs/` ini.
4. Commit & push — gambar otomatis muncul di README utama.
